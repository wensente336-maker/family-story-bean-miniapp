# 家庭故事豆（家庭录音豆）

这是一个以家庭原声为核心的 Web MVP：上传录音或带音轨视频，转写并确认值得保存的片段，再制作**声音明信片**（文字、图片、原声）或**家庭留声机**（原声、解说、混音）。作品支持家庭内播放与互动、限时分享和回收站恢复。

完整的环境要求、依赖安装、数据库 `0001`～`0024` 初始化、启动命令和故障排查，见 **[本地部署与运行说明](docs/local-development.md)**。

```text
web/          React + TypeScript + Vite Web 客户端
backend/      FastAPI、Celery Worker、SQL 迁移与本地媒体存储
docs/         架构图、部署说明和阶段记录
miniprogram/  早期小程序参考，不参与当前 Web 启动
video/        项目展示视频素材与工程
```

本地默认地址：Web `http://127.0.0.1:4173`，API `http://127.0.0.1:8000`。当前默认隐藏新的漫画与绘本创建入口，旧作品代码仍保留。
