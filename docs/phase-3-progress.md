# 阶段 3 进展：微信登录与家庭空间

更新日期：2026-09-18  
阶段状态：阻塞（等待真实微信 AppID/Secret）

## 目的和作用

将用户的微信身份稳定映射为家庭故事豆账号，使录音、转写、高光和作品始终归属于明确家庭，并在服务端拒绝跨家庭访问。

## 前置依赖

- 阶段 2 已确认。
- PostgreSQL、Redis、API 和小程序配置机制正常。
- 真实微信授权验收仍需要小程序测试号或正式 AppID，以及仅保存在服务端的 AppSecret。

## 已完成开发

- 微信 code 换取身份的生产适配器，以及可关闭的开发模拟适配器。
- OpenID HMAC 脱敏存储、签名访问令牌、过期与篡改校验。
- 首次创建家庭、恢复既有家庭、修改家庭名称、添加和修改成员接口。
- 所有家庭读取和写入均同时校验当前用户与家庭所有权。
- 统一未登录、登录失效、参数错误和无权限错误格式。
- 小程序登录守卫、本地会话恢复、首次建家页、家庭管理页和错误状态页。
- 阶段 3 可逆数据库迁移，以及更新后的 OpenAPI。

## 已完成验证

- 后端测试 20 项通过。
- 小程序契约与会话测试 4 项通过。
- 同一模拟微信身份连续 20 次重新登录，均恢复同一家庭。
- 两个家庭共 20 次双向交叉访问，拒绝率 100%。
- 真实 API + PostgreSQL 联调：登录 200、建家 201、自有家庭访问 200、跨家庭访问 404、会话恢复成功。
- 阶段 3 迁移正向、回滚、重新执行均成功。
