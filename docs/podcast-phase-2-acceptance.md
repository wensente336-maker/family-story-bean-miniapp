# 家庭播客新版阶段 2 验收记录

## 阶段结论

阶段 2“声音素材确认台”已完成，等待产品确认。当前真实演示录音保持在草稿第 2 修订版，没有代替用户点击“确认声音素材”，也没有启动阶段 3 的 AI 串讲生成。

## 目的和作用

把转写、高光候选和用户修订转化为可追溯、可试听、可锁定的声音事实。后续 AI 只能使用已确认版本中的人物、原话、顺序和时间边界。

## 前置依赖

- 新版阶段 1 已确认。
- 录音、转写、说话人映射、高光候选和短时播放地址可用。
- `podcast_projects`、`podcast_versions`、`podcast_material_sets` 与 `podcast_materials` 已创建。

## 已完成开发任务

- 新增 `/recordings/{id}/materials` 声音素材确认台。
- 从同一录音内已保留的 1～3 个高光创建草稿。
- 按高光原句匹配真正对应的转写片段，不再默认取第一条上下文证据。
- 展示并永久保留 ASR 原始转写。
- 支持编辑播客采用的确认文本，但不覆盖原文。
- 支持家庭成员身份确认，并同步说话人映射。
- 支持铺垫、高光、回应、收尾四类片段角色。
- 支持片段上移、下移、删除和连续排序。
- 支持以 0.1 秒粒度修改开始和结束边界，并按边界试听。
- 支持“仅家庭内部使用”隐私标记。
- 支持保存草稿、确认锁定和从已确认版本创建新修订。
- 确认操作要求所有片段均已选择家庭成员。
- 确认后的版本不可原地修改；再次修改创建新的播客版本。

## API 与迁移

新增接口：

- `GET /v1/recordings/{recording_id}/podcast-material-set`
- `POST /v1/recordings/{recording_id}/podcast-material-set/draft`
- `PUT /v1/recordings/{recording_id}/podcast-material-set`

新增迁移 `0016_podcast_material_confirmation.sql`：

- 素材集记录转写修订号和确认用户。
- 素材记录来源高光 ID。
- 同一录音在 MVP 中只维护一个播客项目。
- 提供完整 down 迁移。

## 已知边界

- 本阶段不生成 AI 串讲脚本、TTS 或最终播客。
- MVP 只允许同一段录音中的 1～3 个声音片段。
- 当前隐私标记只进入声音事实；阻止外部分享的执行逻辑将在阶段 7 接入。
- 用户必须亲自点击“确认声音素材”才能形成正式锁定版本；当前演示草稿尚未锁定。

## 下一阶段门禁

用户确认阶段 2 后，进入阶段 3“AI 第三人称串讲引擎”。阶段 3 只消费锁定的声音素材版本，并为每段解说保存素材依据。
