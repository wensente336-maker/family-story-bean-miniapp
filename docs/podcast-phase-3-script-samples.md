# 家庭播客阶段 3：三类串讲样例

以下三份样例使用同一组已确认声音素材，仅改变第三人称串讲风格。家庭原声逐字引用确认稿，解说不冒充家人，也不补写素材中不存在的事件。

## 共同声音事实

1. 妈妈：“哈哈哈哈，行了行了，你们俩先把桌子擦干净。”
2. 爸爸：“什么叫一点信心？我这可是祖传手艺。最后一颗西红柿，隆重下锅！”
3. 妈妈：“今天最好吃的不一定是汤，最好记的一定是这颗会飞的西红柿。”

## 温暖陪伴

1. 解说：这是一个被家人亲口记住的时刻。

3. 解说：故事继续，接下来听见爸爸留下的声音。

7. 解说：声音停在这里，这个家庭时刻已经被好好收藏。

音乐建议：`warm-acoustic-light`。

## 轻松有趣

1. 解说：这一回，家里的日常悄悄有了喜剧节奏。

4. 爸爸原声：什么叫一点信心？我这可是祖传手艺。最后一颗西红柿，隆重下锅！
