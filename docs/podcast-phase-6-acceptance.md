# 新版阶段 6 验收：播客成品页、封面与标签

## 目的与作用

把阶段 5 生成的 MP3 变成可辨认、可管理、可收藏的家庭作品，并确保封面、标题、简介和标签编辑与音频混音完全解耦。

## 前置依赖

- 新版阶段 5 已确认。
- 播客版本状态为 `COMPLETED`，且存在 MP3 对象与渲染时间线。
- 私密对象存储支持图片读取、替换和删除。

## 交付物

1. 播客成品页 `/recordings/:id/podcast`：封面、标题、简介、响应式播放器、时长、章节、版本、MP3 下载和原声溯源。
2. 封面上传、焦点裁剪、替换和删除接口。
3. 服务端将 JPG/PNG/WebP 重新解码为 1200×1200 主图和 320×320 缩略图，统一输出 WebP，不保留 EXIF/GPS/设备信息。
4. 无照片时的默认家庭声波封面。
5. 8 类预置家庭标签、自定义标签、每期 5 个上限、大小写无关去重和时间线按标签检索。
6. 标题、简介、封面和标签独立更新 API，不修改音频指纹、对象或版本号。
7. Pillow 图片处理依赖与对应回归测试。

## 安全与产品规则

- 仅接受 5MB 以内的 JPG、PNG 和 WebP，同时校验 HTTP 媒体类型与图片真实编码。
- 原图不直接对外暴露，公开可用的衍生图不包含 EXIF/GPS。
- 封面替换后删除旧主图和旧缩略图，已签发的旧地址随即失效。
- 作品信息编辑不调用 TTS 或 FFmpeg，不更改音频指纹和播客版本号。
- 封面与音频继续通过短时签名地址读取，页面不暴露对象存储键。

## 完成标准与结果

- JPG、PNG、WebP 成功处理；GIF、PDF、文本、空文件和超限文件有明确拒绝规则。
- 输出图像固定为 1:1，主图和缩略图重新编码后无 EXIF。
- 封面替换后旧签名地址返回 404，删除封面后恢复默认声波封面。
- 重复标签、超过 5 个标签和空白标题均被拒绝。
- 修改元数据前后的 `audio_asset_fingerprint` 和 `version` 保持一致。
- 后端全量回归 201 项通过；前端 17 项通过；TypeScript/Vite 生产构建通过。
- Web `http://127.0.0.1:4173/` 与 API `http://127.0.0.1:8000/health` 本地可访问。

## 用户验收路径

1. 在阶段 5 完成页点击“打开播客成品”。
2. 播放、暂停、拖动进度，点击节目章节定位，并下载 MP3。
3. 选择一张家庭照片，调整水平/垂直焦点后保存；再替换或删除。
4. 修改标题、简介，选择预置标签并添加自定义标签。
5. 进入成长时间线，通过标签检索已完成的家庭播客。

用户确认后才进入新版阶段 7：私密分享与社交分发。
