# 新版阶段 7 验收记录：私密分享与社交分发

## 阶段目的

让已完成的家庭播客在不公开逐字稿、人物资料和永久存储地址的前提下，通过可过期、可撤销的链接分享给家人或社交平台。

## 已交付

- 播客成品页增加“限时私密分享”，支持 24 小时、3 天、7 天。
- 支持复制链接、Web Share 系统分享；系统分享不可用或失败时回退为复制。
- 支持下载已上传的分享封面。
- 支持查看分享状态、到期时间、访问次数并即时撤销。
- 增加服务端公开分享卡片，包含标题、简介、标签、封面、播放器及 Open Graph 元信息。
- 每次有效访问重新签发最多 10 分钟的音频和封面地址。
- 数据库只保存分享令牌的 SHA-256 摘要，不保存可用的原始令牌。
- 访问日志仅保存分享 ID 和访问时间，不保存 IP、User-Agent、逐字稿或原始录音内容。
- 家庭关闭分享权限时，已有播客分享链接同步撤销。

## 安全边界

- 分享页只展示播客成品层信息，不提供逐字稿、原声片段清单、家庭成员 ID 或对象存储键。
- 已经签发的短时媒体地址最多保留 10 分钟；撤销或过期后不能再获得新的签名地址。
- 本地 HTTP 只用于 MVP 联调。真正投放社交媒体前必须使用 HTTPS 和可公网访问的规范域名。
