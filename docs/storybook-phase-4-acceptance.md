# 沉浸式电子书阶段 4 验收：声音导演脚本驱动漫画

## 目的与作用

让 AI 漫画不再是与声音并列的独立素材，而是声音导演脚本的视觉结果。每一幕先确定声音事实、叙事作用和时间范围，再生成唯一对应的画面；播放器只依赖同一 `page_index` 切换画面、字幕、解说和家庭原声。

## 前置依赖

- 阶段 3 的声音事实、7 幕导演脚本、确认门槛和统一音频主时钟已完成。
- 用户标注的苗苗、妈妈、爸爸原声及毫秒级边界可追溯。
- Web 书册阅读器能够按 experience scene 和 cue sheet 驱动页面与音频。

## 本阶段交付

- 建立苗苗、妈妈、爸爸三人的统一人物参考图，锁定年龄、脸型、发型、服装与色彩。
- 依据 7 幕导演脚本生成 7 张独立 16:9 绘本画面：封面、平静晚饭、意外发生、苗苗原声、全家笑声、爸爸回应、共同收尾。
- 保留无损 PNG 创作源文件，并生成约 215–256 KB/张的 WebP 展示副本，7 张页面资源从约 17.5 MB 降至约 1.6 MB。
- 每个导演场景新增 `asset_url`，由后端故事计划和 experience session 原样传递给前端。
- 画面资产与 `page_index`、`audio_start_ms`、`audio_end_ms` 绑定；阅读器优先呈现该幕专属画面，不再裁切复用旧四格图。
- 导演台增加逐幕缩略图，让用户在确认声音故事线之前同时审核画面意图与声音安排。
- 通用故事仍保留旧漫画面板作为兼容性后备，本次“会飞的西红柿”使用完整的新画面链。

## 完成标准

- 7 幕均有独立、可访问的图像资产，且没有图内文字、水印或额外家庭成员。
- 三位人物在 7 幕中的年龄、发型、服装和家庭关系保持一致，妈妈明确为中年母亲形象。
- 每幕的 `asset_url` 与其声音导演脚本使用同一个 `page_index`。
- 端到端体验音轨包含 7 个 scene、7 个 cue，总时长 34,967 ms；所有场景音频区间首尾连续、单调递增并覆盖整条音轨。
- 真实验收后计划恢复为 `DRAFT`，不会替用户确认或发布内容。
- 后端 102 项测试通过；前端 17 项测试与生产构建通过。

## 阶段边界

本阶段完成逐幕漫画生成、人物一致性和与音频时间轴的绑定。PDF 排版、限时分享成品、面向任意新录音的异步图像生成队列，以及用户逐幕重画工作流属于后续阶段。
