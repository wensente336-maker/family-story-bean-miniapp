# 家庭故事豆 Web MVP：十阶段门禁计划

## 执行规则

每阶段完成后提交交付物、测试结果和已知边界，状态改为“待确认”并停止。只有用户明确确认当前阶段后，才进入下一阶段。

## 阶段门禁摘要

1. 建立 React、TypeScript、Vite、响应式首页、路由和 PWA 外壳。
2. 建立 Web API Client、CORS、环境配置和前后端契约测试。
3. 完成 Web 登录、首次建家、成员管理和家庭级数据隔离。
4. 完成浏览器音频选择、签名直传、真实格式及时长校验。
5. 完成 Celery 任务、幂等重试、HTTP 轮询和页面恢复。
6. 完成 ASR、时间戳、说话人分离、成员映射和文本校正。
7. 完成高光评分、原话追溯、故事板及用户确认。
8. 完成四格漫画、人物一致性、单格重试和长图导出。
9. 完成播客脚本、TTS、原声剪辑、混音、播放和下载。
10. 完成成长时间线、级联删除、HTTPS、监控和全链路验收。

旧微信小程序代码保留作为视觉与逻辑参考，不再作为当前产品交付入口。现有 FastAPI、PostgreSQL、Redis、Celery、数据库模型及故事板契约继续复用。
