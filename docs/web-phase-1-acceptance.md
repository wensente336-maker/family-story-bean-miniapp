# Web 阶段 1 验收：工程与首页 UI

验收日期：2026-09-19  
确认日期：2026-09-19  
阶段状态：已确认

## 目的

建立可在手机和电脑浏览器运行的家庭故事豆入口，让用户首屏即可选择录音、查看处理进度、高光和漫画/播客入口。

## 交付物

- React + TypeScript + Vite 工程。
- 响应式首页、桌面侧栏和移动端底部导航。
- 首页、时间线、家庭、录音、高光、漫画、播客及隐私路由。
- Mock 首页数据、加载状态和录音选择交互。
- PWA manifest、Service Worker 和专属 favicon。
- 原创家庭晚餐插画，作为高光卡片示例内容。

## 完成标准与结果

- 生产构建成功。
- 320px 手机宽度无横向溢出。
- 1440px 桌面宽度无横向溢出。
- 首页图片加载失败数为 0。
- 浏览器路由跳转和返回正常。
- 浏览器控制台无错误或警告。
- 音频选择仅在本地展示文件信息，没有上传行为。

## 已知边界

- 当前使用 Mock 数据，真实 API 在 Web 阶段 2 接入。
- 登录与家庭管理为规划路由，真实能力在 Web 阶段 3 接入。
- 上传、AI 高光、漫画和播客入口可查看，但真实处理按阶段 4–9 开发。
- 本地开发使用 HTTP；测试及生产必须使用 HTTPS。

## 确认点

用户已确认首页信息层级、视觉方向、手机/桌面布局和主要入口，Web 阶段 2 已启动。
