# Web 阶段 10 验收：时间线、隐私与 MVP 收口

状态：已确认（2026-09-20，本地 MVP；公网发布门禁未全部满足）

## 目的和作用

把单次录音生成能力收口为可持续使用的家庭记忆产品：内容能按时间回看，作品能限时分享，家人能控制原始录音保留时间，并能删除单个作品、整段录音或整个家庭空间。

## 前置依赖

- Web 阶段 9 已确认。
- 漫画、播客、对象存储、PostgreSQL、Redis 和 Worker 链路可用。
- 本轮仍遵循用户确认的 HTTP 本地 MVP 运行方式；公网 HTTPS 需要明确部署目标后再实施。

## 本轮产品约定

- 所有家庭内容默认私密；公开页只暴露指定作品，不返回家庭资料或原始录音。
- 分享链接默认 24 小时有效，可在隐私页改为 1–168 小时，可随时撤销。
- 服务端只保存分享令牌的 SHA-256 摘要，明文令牌只在创建响应中出现一次。
- 原始录音默认保留 7 天，可设置为 1–30 天；过期任务只删除原始文件，保留转写、高光及已生成作品。
- 删除录音会级联删除其转写、高光、漫画、播客和分享记录，并清理对应对象文件。
- 删除家庭空间要求输入家庭名称再次确认，完成后立即退出登录。

## 已交付

- 成长时间线：按内容类型、家庭成员、开始日期和结束日期筛选录音、高光、漫画及播客。
- 隐私中心：原始录音保留策略、默认分享时长、总分享开关、分享记录和撤销入口。
- 漫画与播客详情页：按家庭默认时长创建限时链接并复制。
- 无登录公开分享页：播客支持播放，漫画支持阅读；过期或撤销后统一显示失效状态。
- 删除能力：单个作品、整段录音和整个家庭空间；数据库与本地对象文件级联清理。
- 每小时原始录音过期清理任务；现有录音迁移时补齐保留日期，新录音读取家庭当前保留设置。
- 家庭级运行指标：上传、分析、作品生成、处理 P95、删除成功率和有效分享数。
- 数据库迁移 `0010_timeline_privacy`、OpenAPI 更新、可重复运行的隔离级联验证脚本。

## 验收证据

- 后端 88 项自动测试全部通过，包括 100 个随机外部作品 ID 的跨家庭删除拒绝、令牌摘要、过期原始录音清理行为、播客历史版本文件清理和迁移可逆性。
- Web 13 项自动测试全部通过，TypeScript 检查和 Vite 生产构建通过。
- `npm audit --omit=dev`：0 个已知漏洞。
- 真实 PostgreSQL 迁移成功：2 个现有家庭均生成隐私默认设置，已保存原始录音不存在缺失保留日期的记录。
- 真实演示家庭时间线聚合出 7 条内容，覆盖录音、高光、漫画和播客四类。
- 本地真实指标查询成功：2 条录音样本的上传、分析和生成成功率均为 100%，处理 P95 为 4.545 秒；样本过小，不作为生产性能结论。
- 隔离数据验证通过：分享创建/打开/撤销、数据库级联、两个对象文件清理和删除审计全部成功，测试数据随后自动清理。
- 浏览器验证通过：公开播客页返回音频 `206 Partial Content`，撤销后同一地址返回 404 并显示“链接已失效”。

## 已知边界与发布建议

- 当前适合本地或受控内网演示，不建议直接暴露到公网。
- 公网发布前必须配置 HTTPS、生产域名、独立对象存储、强随机签名密钥、短信服务、集中日志和告警。
- 真实 15 分钟音频 P95、模型成本、作品转化率需要接入生产埋点后统计。
- 删除流程当前面向本地对象存储；迁移至云对象存储时需增加失败重试和补偿队列。
- 必须完成 10 个授权家庭、每家至少 5 段录音的灰度，才能宣称原十阶段计划中的“生产发布验收”完成。
