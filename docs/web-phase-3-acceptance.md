# Web 阶段 3 验收：登录与家庭空间

验收日期：2026-09-19  
阶段状态：待用户确认

## 目的和作用

建立 Web 用户身份、登录恢复和家庭数据归属，使首页、录音及未来生成内容只能由所属家庭访问。

## 前置依赖

- Web 阶段 2 已确认。
- PostgreSQL、Redis、FastAPI 和 Web API Client 可用。
- 本地 MVP 使用一次性开发验证码；公网部署前必须配置真实短信供应商。

## 交付物

- 手机号验证码申请与验证接口。
- Redis 验证码有效期、重发限制、错误次数限制和单次消费。
- 手机号 HMAC 摘要存储，不保存手机号明文。
- 签名访问令牌、会话恢复和受保护路由。
- 首次创建家庭、修改家庭名称和添加家庭成员。
- 家庭级服务端权限校验和受保护首页。
- 登录页、建家页、家庭管理页及退出流程。
- Web 身份数据库迁移和更新后的 OpenAPI。

## 完成标准与结果

- 后端自动化测试 27 项通过。
- Web 自动化测试 6 项通过。
- TypeScript 编译及生产构建通过。
- npm 依赖审计为 0 个已知漏洞。
- 同一测试身份连续 20 次重新登录均恢复同一家庭。
- 两个家庭双向交叉访问拒绝率 100%。
- 未登录访问家庭和首页均返回 401。
- 验证码成功后立即失效，重复使用返回 401。
- 60 秒内重复申请返回 429；连续五次错误后挑战失效。
- 数据库迁移正向、回滚、重新执行全部成功。
- 浏览器完成登录、建家、刷新恢复、添加成员和退出全流程。
- 320px 手机、约 760px 平板和桌面布局无关键内容裁切。

## 当前边界

- 开发环境通过 `ALLOW_DEV_WEB_OTP=true` 使用固定测试验证码，页面会明确显示“开发验证码”。
- 默认配置关闭开发验证码；未配置短信供应商时返回 `OTP_DELIVERY_UNAVAILABLE`，不会生成通用后门。
- 当前退出会清除浏览器令牌；已签发令牌最多保留到两小时有效期结束。服务端主动吊销将在部署安全加固时加入。
- 短信供应商、域名和 HTTPS 属于部署配置，不影响本地 MVP 验收。

## 确认点

用户确认登录方式、首次建家、成员管理、登录恢复和家庭隔离后，才能启动 Web 阶段 4。
