# Web 阶段 4 验收：15 分钟录音上传

状态：已确认

## 目的和作用

为后续 ASR、高光发现、漫画和播客建立可信输入入口。浏览器预检用于即时反馈，服务端真实媒体检测、时长、摘要和家庭归属才是安全边界。

## 前置依赖

- Web 阶段 3 已确认。
- PostgreSQL、Redis 和 FFprobe 可用。
- 支持格式冻结为 MP3、M4A、WAV、AAC；最长 15:00，最大 100 MB。
- 本地 MVP 使用私有目录存储适配器，接口可替换为 S3/OSS。

## 已交付

- 响应式录音上传页及首页选择入口。
- 浏览器扩展名、大小、真实可读时长预检。
- 浏览器 SHA-256、上传进度、取消和无需重新选择文件的重试。
- 创建录音、短期签名 PUT 直传、上传完成回调。
- 服务端 FFprobe 真实格式及时长检测、SHA-256 完整性校验。
- 家庭归属校验、录音列表、详情和草稿删除接口。
- 重复上传完成回调幂等。
- 首页展示真实的最新录音状态。
- 数据库迁移 `0004_recording_upload`，已验证升级、回滚、再升级。

## 验收结果

- 后端自动测试：39 项通过。
- Web 自动测试：8 项通过；TypeScript 与生产构建通过；npm 依赖审计 0 个漏洞。
- MP3、M4A、WAV、AAC 四种格式及 5、10、15 分钟合法 WAV：全部通过。
- 50 次合法样本验证：50/50，通过率 100%。
- 15:01、空文件、伪造 MP3、损坏内容、摘要不一致：全部拒绝。
- 真实 HTTP 链路：登录、建家、创建录音、PUT 上传、完成校验、列表查询全部通过。
- 同一完成回调执行两次：返回同一录音 ID。
- 失败草稿删除：数据库记录与本地对象均删除。
- 浏览器验收：5 秒 WAV 上传成功，首页显示“已上传 / 音频已安全保存 100%”；刷新后登录、家庭和录音状态均可恢复。

## 已知边界

- 本地预览使用私有目录模拟对象存储；正式部署需要接入 S3/OSS/COS 签名服务。
- 阶段 4 只负责可靠接收与校验音频，不启动 ASR 或 AI 任务；异步任务属于阶段 5。
- 已上传原始录音的用户级级联删除和到期清理由阶段 10 完成；本阶段只允许删除未进入处理的草稿或失败记录。

## 确认门

用户确认合法上传、超时/损坏拒绝、失败重试和首页真实状态后，才能启动 Web 阶段 5。
