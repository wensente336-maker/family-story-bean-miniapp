# Web 阶段 6 验收：音频转写与人物映射

状态：已确认

## 目的和作用

将已上传的家庭录音转换为可播放、可回溯、可校正的结构化文本，并建立“说话人 A/B/C → 家庭成员”的人工确认关系。这是阶段 7 高光发现、原话引用和故事板生成的可追溯数据基础。

## 前置依赖

- Web 阶段 5 已确认。
- PostgreSQL、Redis、Celery Worker 和私有对象存储可用。
- 服务器已安装 FFmpeg，并配置本地 `mlx-whisper` 模型路径。
- 家庭成员和录音的家庭归属已在阶段 3–4 建立。

## 已交付

- FFmpeg 预处理：单声道、16 kHz PCM、语音频段滤波与响度归一化。
- 本地 `mlx-whisper` 真实转写：片段时间戳、字词时间戳、置信度和无语音幻觉过滤。
- 转写期间租约心跳，避免长音频被 Beat 误判为失联任务。
- 保守的 A/B/C 声学分组；不自动声称识别真实人物。
- 家庭成员映射、逐段说话人调整、文本校正、原始文本保留和修订版本号。
- 转写查询、片段修改、人物映射和短时签名回放 API，全部执行家庭归属校验。
- HTTP Range 音频回放，页面点击句子即跳到原音时间点。
- Web 转写校对页：低置信度提示、播放、人物映射、文本修改与刷新恢复。
- 数据库迁移 `0006_transcription`，已验证升级、回滚、再升级。

## 完成标准与验收结果

- 经真实上传链路提交的 10 秒合成中文对话，由 Worker 转写至 `READY_FOR_SELECTION`，耗时 4.58 秒，产生 3 个可追溯片段。
- 其中置信度 0.5837 的片段被正确标记为需要校对。
- 浏览器完成 A/B/C 映射、转写文本修正和刷新持久化；录音修订号上升至 7。
- 签名音频回放的 Range 请求返回 HTTP `206 Partial Content`。
- 20 条合成回归样本全部完成预处理与转写，覆盖成人、儿童音高模拟、背景噪声、重叠语音和静音；静音未产生幻觉片段。
- 精确 15:00 的 WAV 上传、校验、预处理和转写全链路通过，Worker 耗时 41.917 秒，产生 252 个转写片段，最终进度 100%。
- 后端 56 项自动测试、Web 8 项自动测试全部通过；TypeScript 检查与 Web 生产构建通过；npm 依赖审计为 0 个漏洞。
- OpenAPI 已重新导出，阶段 6 的转写、人物映射和回放端点均在契约中。

## 评估边界

- 20 条回归集是合成的工程稳定性样本，证明预处理、ASR 调用和静音过滤可工作，不等价于真实家庭环境的字错率验证。
- A/B/C 是启发式声学分组，重叠说话、短句和相似声线可能需要用户校正；产品界面不将其包装为真人身份识别。
- 上线前仍需用经授权的真实成人、儿童、多人重叠和家庭噪声样本建立 WER/CER 与说话人分组准确率基线。
- 当前为 Apple Silicon 本地模型验收；生产 GPU 容量、模型版本固定、监控和容灾在阶段 10 处理。

## 确认门

用户确认转写页、原音回放、低置信度校对、说话人映射和 15 分钟处理结果后，才能启动 Web 阶段 7。
