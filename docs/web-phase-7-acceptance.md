# Web 阶段 7 验收：AI 高光与家庭故事板

状态：已确认

## 目的和作用

从普通家庭对话中找出最值得留下的片段，并把它们转换成漫画与播客可共用的统一故事板。最重要的安全约束是：家人的“直接引语”只能来自原始转写，而且可回到对应音频时间戳。

## 前置依赖

- Web 阶段 6 已确认。
- `storyboard-v1` JSON Schema 已冻结。
- 转写片段、字词时间戳、人物映射和原声签名回放可用。

## 已交付

- 候选片段召回和确定性 Top 3 排序。
- 欢乐、温暖、惊喜、情绪表达、家人参与度、故事完整度和转写可信度的可解释分数。
- 统一故事板：标题、场景、人物、开场、转折、结尾、情绪曲线、重点原话与敏感标记。
- 100% 的直接引语来源绑定：转写片段 UUID、起止毫秒和原文。
- 用户可保留、不保留、试听、展开故事板、查看推荐原因、调整片段边界。
- 边界调整后同步重建原话证据和故事节点；刷新页面后保留状态与边界均可恢复。
- 从转写页进入高光时按当前修订重建，确保不引用校正前的旧文本。
- 用户行为记入 `moment_feedback`，后续可用于个性化和真实指标评估。
- 首页已接入真实高光摘要。
- 数据库迁移 `0007_moments` 已验证升级、回滚和再升级。

## 验收结果

- “周日晚餐”演示录音生成 3 个独立高光，识别出“爸爸把西红柿掉进汤里”为排名第一的欢乐时刻。
- 浏览器完成第一条高光的原声试听、保留、故事板展开、原话证据查看和边界从 `3.28–7.12` 秒调整为 `3.3–7.0` 秒。
- 刷新后仍显示“已保留 1 个时刻”与 `3.3–7.0` 秒边界。
- 合成黄金集覆盖 10 个虚拟家庭、50 段对话；Top 3 命中 50/50，直接引语可追溯率 100%，虚构直接引语 0，同输入结构稳定。
- 后端 65 项自动测试、Web 8 项自动测试全部通过；TypeScript 检查与生产构建通过；OpenAPI 已重新导出；npm 审计为 0 个漏洞。

## 评估边界

- MVP 当前使用可解释的本地确定性排序，尚未接入外部 LLM 重排。这保证了低成本、可复现与零虚构原话，但复杂叙事的语义理解上限较低。
- 50 段黄金集为合成场景标签，不是“真实 10 个家庭＋两位独立人工标注”。因此 100% 命中只证明工程契约和显著特征可工作，不代表真实用户满意度。
- 真实 Top 3 保留率需在取得授权的家庭内测后通过 `moment_feedback` 评估；上线标准仍是不低于 70%。
- 如后续接入 LLM，只允许它重排候选与摘要叙事，直接引语仍必须通过转写片段 ID 校验。

## 确认门

用户确认 Top 3、试听、故事板、原话证据、保留/不保留与边界调整后，才能启动 Web 阶段 8。
