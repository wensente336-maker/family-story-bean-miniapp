# 家庭故事豆 Web MVP

移动端优先的 React + TypeScript + Vite Web App。当前默认连接真实 API，已支持登录、家庭空间、录音上传、异步处理、转写校对、Top 3 高光、四格家庭漫画和家庭播客。

## 本地运行

```bash
npm install
npm run dev
```

默认地址：`http://127.0.0.1:4173/`

复制 `.env.example` 为 `.env.local` 后可以选择数据源：

```env
VITE_API_BASE_URL=http://127.0.0.1:8000
VITE_DATA_SOURCE=api
```

`VITE_DATA_SOURCE=api` 时，登录、家庭空间和首页会通过 HTTP 请求 FastAPI。开发测试验证码由后端 `.env` 控制，不写入 Web 前端。

## 构建

```bash
npm run build
```

构建产物位于 `dist/`。本地开发使用 HTTP，测试和生产部署必须启用 HTTPS。

## 当前边界

- 首页、响应式布局、浏览器路由、PWA 外壳和 Web API Client 已经完成。
- 录音选择、浏览器时长预检、SHA-256、进度、取消和原文件重试已完成。
- 手机号登录、首次建家、家庭管理和真实首页 API 已接入。
- 处理页每 2 秒轮询，页面隐藏时停止，恢复可见或刷新时从服务端恢复进度。
- 任务失败时展示错误与重试次数，支持人工重跑。
- 处理完成后进入 `/recordings/:id/transcript`，可点击句子定位原音，低置信度片段会突出提示。
- 支持将 A/B/C 整体映射到家庭成员，也支持逐句改变说话人和修正文本；刷新页面仍从 API 恢复。
- 从转写页进入高光时，会按当前转写修订重建 Top 3，避免展示校正前的旧引语。
- `/recordings/:id/moments` 支持分段试听、保留、不保留、边界调整、故事板展开、原话证据和推荐原因。
- `/comics/:id` 展示共享人物设定的四格漫画，明确区分可溯源原话与 AI 旁白，支持单格重画和 1080 px 竖版 PNG 长图导出。
- `/podcasts/:id` 提供节目封面、播放器、MP3 下载、原声溯源试听、高光排序、开场/片尾编辑和幂等重混。
- 页面与数据中分别标识“AI 主持人”和“家人真实原声”，并明确提示不使用声音克隆。
- 漫画候选版使用内置生成资产；不代表已接入通用的实时生图服务。
- 本地使用可替换的私有存储与本地 ASR 适配器；生产 S3/OSS 、GPU 容量和真实家庭语音准确率评估在上线前补齐。
